# OMV Buyer Tagging and Dispo SOP

## Purpose
Create a clean, repeatable system inside Follow Up Boss (FUB) so Off Market Vault can organize buyers, track dispo activity, and move signed deals to the right buyers faster.

## Core Systems
- **Investor Base** = build buyer list, skip trace active investors, property website/details page
- **FUB** = main CRM, buyer tracking system, outreach system, and dispo operations hub

## Main Buyer Smart Lists
Keep the sidebar lean.

- **Cash Buyers** = master buyer list
- **VIP Buyers** = Cash Buyer + VIP Buyer
- **Active Bidders** = Cash Buyer + Offer Submitted
- **Proven Buyers** = Cash Buyer + Closed Buyer

## Buyer Quality Tags
Use these to rank buyer strength.

- **A Buyer** = strongest buyers, high confidence
- **B Buyer** = solid buyers, but less proven
- **C Buyer** = newer or less proven buyers
- **VIP Buyer** = manual only, based on JJ's judgment

## Buyer Activity Tags
Use these to track buyer behavior during dispo.

- **Walkthrough Showed**
- **Offer Submitted**
- **Won Bid**
- **Closed Buyer**

### Definitions
- **Walkthrough Showed** = buyer actually showed up to the appointment/walkthrough
- **Offer Submitted** = buyer has submitted an offer on a deal
- **Won Bid** = buyer won the deal but may not have closed yet
- **Closed Buyer** = buyer actually closed on the deal

## Funding Tags
Use one or both.

- **Buys Cash**
- **Buys Hard Money**

If a buyer uses both, apply both tags.

## Buyer Type Tags
Tag each buyer by strategy when known.

- **Buyer Type - Flipper**
- **Buyer Type - Landlord**
- **Buyer Type - Builder**

A buyer can have more than one type tag if applicable.

## Offer Tracking Tags
When JJ sends an offer, use these tags.

### Offer Send Type
- **Offer Sent - Live** = JJ sent/explained the offer live, on the phone or in person
- **Offer Sent - Not Live** = offer/docs were sent without JJ being live with them

### Offer Outcome
- **Offer Outcome - Signed**
- **Offer Outcome - Not Signed**

## Offer Stage Rule
- **Offer Sent** is the stage once an offer/package has actually been sent
- Do not treat every seller as hot just because an offer was sent
- If a live offer does not get signed, track why immediately

## Seller Offer Workflow
1. Seller is being worked and qualifies for an offer
2. JJ prefers to send/explain offers live whenever possible
3. Once offer/package is sent, set stage to **Offer Sent**
4. Add tag:
   - **Offer Sent - Live** or
   - **Offer Sent - Not Live**
5. Add outcome tag:
   - **Offer Outcome - Signed** or
   - **Offer Outcome - Not Signed**
6. If not signed, note the reason
7. If signed, move deal into dispo process

## Common Not Signed Reasons
Add a quick note in FUB when applicable.

Examples:
- needs to think about it
- spouse/family decision
- wants price change
- daughter/occupant needs replacement housing
- reviewing docs
- ghosted
- other

## Dispo SOP After Seller Signs
Once a seller signs, dispo begins.

### 1. Build Quick Buyer Breakdown
Before sending full details, start with a clean quick breakdown.

Include:
- address
- price
- beds/baths
- sqft
- lot size
- rehab/condition
- ARV
- exit strategy
- closing date
- EMD
- access details

### 2. Access Language
Keep access simple.

Use:
- **appointment only**

If relevant, add context such as:
- cameras on property
- JJ walks serious buyers personally

### 3. Buyer Outreach Flow
1. Send quick breakdown
2. If buyer is interested in the deal and number, send fuller details and/or Investor Base property link
3. Set appointment/walkthrough time
4. Ask whether they are using **cash** or **hard money**
5. Track attendance and engagement in FUB

### 4. Track Buyer Actions in FUB
When applicable, tag buyers with:
- **Walkthrough Showed**
- **Offer Submitted**
- **Won Bid**
- **Closed Buyer**

Also keep funding/type tags updated:
- **Buys Cash**
- **Buys Hard Money**
- **Buyer Type - Flipper**
- **Buyer Type - Landlord**
- **Buyer Type - Builder**

## Buyer Database Goal
The long-term goal is to build the ultimate buyer list for OMV.

That means tracking:
- who responds fast
- who actually shows up
- who submits offers
- who wins bids
- who closes reliably
- what type of buyer they are
- whether they use cash, hard money, or both
- whether they belong in VIP

## Team Rules
- Keep the FUB sidebar clean, do not create too many smart lists
- Use tags heavily in the backend
- VIP status is manual only and decided by JJ
- Accuracy matters more than speed
- Keep buyer organization simple, searchable, and useful

## Current Standard Summary
- **Cash Buyers** = master list
- **VIP Buyers** = top manual subset
- **Active Bidders** = buyers who have ever submitted an offer
- **Proven Buyers** = buyers who actually closed
- Use tags to track quality, activity, funding, and buyer type
- Use quick breakdowns first, then send Investor Base details when interest is confirmed
