# OMV Seller Offer Follow-Up SOP

## Purpose
Create a clean follow-up system for seller offers inside Follow Up Boss (FUB) so OMV can track objections, keep live deals moving, and avoid losing signable deals through poor follow-up.

## Core Rule
A seller is **not dead** unless they clearly say:
- do not contact me

Do not kill leads too early.

## Main Seller Stages
- **Hot (0-30 Days)** = seller is engaged, deal is alive, but not signed
- **Offer Sent** = offer/package has been sent and is actively pending review

## Stage Rules
### Keep in Offer Sent when:
- offer is out
- seller is actively reviewing
- seller is expected to sign soon
- follow-up is active and immediate

### Move back to Hot when:
- seller did not sign
- seller is still engaged
- the deal is still alive
- conversation has reset back into objection handling, clarification, or timing

### Mark Dead only when:
- seller clearly says do not contact them

## Offer Send Rules
### Default Rule
JJ prefers to send/explain offers live whenever possible:
- on the phone, or
- in person

### Exceptions
Offers can be sent without being live, but that should be rare.

## Offer Tracking Tags
### Send Type
- **Offer Sent - Live**
- **Offer Sent - Not Live**

### Outcome
- **Offer Outcome - Signed**
- **Offer Outcome - Not Signed**

## Immediate Workflow When Offer Is Sent
1. Set seller stage to **Offer Sent**
2. Add one send-type tag:
   - **Offer Sent - Live** or
   - **Offer Sent - Not Live**
3. Add one outcome tag once known:
   - **Offer Outcome - Signed** or
   - **Offer Outcome - Not Signed**
4. Add note with what happened
5. If unsigned, create follow-up task

## Main Reasons Sellers Do Not Sign
Track these in notes when applicable:
- price
- terms
- timeline
- multiple parties need to sign
- confused
- does not know payoff / liens

## Unsigned Offer Workflow
If seller does **not** sign:
1. Add **Offer Outcome - Not Signed**
2. Note the actual objection/reason
3. Create a **24-hour follow-up task**
4. Clarify objection
5. Gather needed info/docs if required
6. Keep lead active
7. If still engaged, move back to **Hot** when the deal is no longer truly in active review mode

## Signed Offer Workflow
If seller **does** sign:
1. Add **Offer Outcome - Signed**
2. Move deal into dispo/sales process
3. Make sure dispo package is prepared correctly
4. Start buyer outreach workflow

## Follow-Up Timing
### Unsigned offers
- follow up within **24 hours**

### Goal of follow-up
- identify the true objection
- resolve confusion
- clarify payoff/liens if needed
- handle multi-signer issues
- move toward signature or clean next step

## Task Standard
For unsigned offers, default task:
- **Follow up on unsigned offer in 24h**

Task purpose:
- call/text seller
- clarify objection
- get decision moving

## Notes Standard
Every unsigned offer should include a short note covering:
- why they did not sign
- what they need next
- who else is involved
- what JJ needs to clarify or solve
- next follow-up timing

## Operating Mindset
- Do not assume unsigned means dead
- Most unsigned offers need better explanation, better timing, or cleaner follow-up
- Keep the pipeline honest
- Keep active deals moving
- Keep real leads warm until they truly opt out

## Team Summary
- **Offer Sent** = actively pending review
- **Hot** = still alive, still engaged, but not truly pending signature anymore
- **Dead** = only after seller says do not contact them
- Default unsigned follow-up = **24 hours**
- Always capture the reason for not signing
- Signed offers move into dispo immediately
